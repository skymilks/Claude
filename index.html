About CrownBids

CrownBids is a full-stack web application that helps Canadian businesses discover government contracts. It combines:

  • Frontend: Vanilla JavaScript, responsive CSS, interactive contract browsing
  • Backend: Node.js/Express API, PostgreSQL database, web scraping service
  • Features: Contract matching, website analysis, smart scoring algorithm

Debugging with Claude Code

Use Claude to identify and fix issues efficiently.

🔧 Scenario: Silent Failures

Users report URL analysis fails without clear errors.

claude-code "Why might URL analysis fail silently? Show me error paths."

Steps:

  1. Claude identifies potential failure points
  2. Ask for enhanced error logging
  3. Create test cases for edge cases
  4. Fix identified issues

🔐 Scenario: Security Review

Identify potential security vulnerabilities.

claude-code "What security measures are in place? Are there vulnerabilities?"

Expected areas Claude reviews:

  • API security headers (Helmet, CORS)
  • Input validation and sanitization
  • Rate limiting configuration
  • Sensitive data exposure

⚠️ Debugging Workflow

  1. Describe the problem clearly
  2. Provide relevant error messages
  3. Ask Claude for potential causes
  4. Have Claude generate fixes
  5. Test thoroughly before committing
